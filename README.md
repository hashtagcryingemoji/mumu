# mumu-guard

Header-only библиотека на C++20: мьютекс, который владеет данными, которые защищает.

`mumu::mutex<T>` хранит значение типа T вместе с его блокировкой. Единственный способ добраться до данных это RAII-guard, который возвращают `lock()` и `try_lock()`, поэтому данные и их критическая секция не могут разъехаться.

## Возможности

- спинлок `mumu::mutex<T>` с acquire/release упорядочиванием
- RAII `mutex_guard`: move переносит владение блокировкой, деструктор снимает её
- `try_lock()` возвращает `std::optional<mutex_guard>`
- debug-детектор рекурсивного захвата, assert срабатывает до спин-цикла
- GoogleTest: однопоточные тесты, move-семантика, гонка потоков, death-тесты

## Сборка и тесты

    cmake -S . -B build
    cmake --build build
    ctest --test-dir build --output-on-failure

Демо-бинарник печатает счётчик, который инкрементят четыре потока.

## Структура

- `mutex.h`: вся библиотека, один заголовок
- `main.cpp`: многопоточное демо
- `test/mutex_tests.cpp`: набор тестов GoogleTest
